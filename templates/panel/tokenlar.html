Yapay zekâ ile siteyi yönetmek

Token ürettikten sonra Claude, ChatGPT veya başka bir araçla sohbet ederek yazı yazdırabilir, taslakları listeletebilir ve yayınlatabilirsiniz. Aşağıda kullandığınız araca göre adımlar var.

Adım 1 — Token üretin

  1. Yukarıdaki “Yeni token” formuna bir ad yazın (örnek: ChatGPT — masaüstü). Ad sadece sizin için; nerede kullandığınızı hatırlamanıza yarar.
  2. Vermek istediğiniz yetkileri işaretleyin. Yalnızca yazı yazdıracaksanız “Yazı oluşturma ve düzenleme” yeterlidir.
  3. Üret'e basın.
  4. Ekranda çıkan uzun metni hemen kopyalayın. Bu metin bir daha gösterilmez; kaybederseniz yenisini üretirsiniz.

Adım 2 — Aracınıza bağlayın

Claude ile (Claude Code / Claude Desktop)

Claude bu siteyi MCP üzerinden doğrudan yönetebilir — en eksiksiz seçenek budur.

  1. Proje klasöründeki .env dosyasını açın.
  2. Şu iki satırı yazın: GC_API_BASE={{ panel_url }}
    GC_API_TOKEN=kopyaladığınız-token
  3. Claude'u kapatıp yeniden açın. Bağlantıyı okumak için yeniden başlaması gerekir.
  4. Sohbete “blog bağlantısını test et” yazın. Bağlantı çalışıyorsa site adınızı ve yazı sayısını döndürür.
ChatGPT ile (kendi GPT'nizi oluşturarak)

ChatGPT'nin ücretli sürümünde kendi GPT'nizi oluşturup bu siteye bağlayabilirsiniz. Menü adları arayüz diline göre değişir; ikisini de yazdım.

  1. GPT'leri Keşfet (Explore GPTs) → Oluştur (Create).
  2. Yapılandır (Configure) sekmesinde en alttaki Yeni eylem oluştur (Create new action).
  3. URL'den içe aktar (Import from URL) kutusuna şu adresi yapıştırın: {{ panel_url }}/api/openapi.json Bu adres, sitenin hangi işlemleri kabul ettiğini ChatGPT'ye kendisi anlatır.
  4. Kimlik Doğrulama (Authentication) bölümünde API Anahtarı (API Key) → Taşıyıcı (Bearer) seçin, token'ı yapıştırın.
  5. Kaydedin. Artık o GPT'ye “yeni bir taslak yazı oluştur” diyebilirsiniz.
Sohbet sitelerinden MCP ile bağlanmak (henüz hazır değil)

Claude ve ChatGPT'nin web arayüzleri artık MCP sunucusu bağlamayı destekliyor:

  • Claude (claude.ai) → Ayarlar (Settings) → Bağlayıcılar (Connectors) → Ekle (Add) → Özel bağlayıcı ekle (Add custom connector)
  • ChatGPT → Ayarlar → Gelişmiş (Advanced) → Geliştirici Modunu (Developer Mode) açın → Bağlayıcılar (Connectors) sekmesi
  • Gemini (gemini.google.com) → sohbet arayüzünde MCP desteği yok. Yalnızca Google AI Studio'da, kod yazarak bağlanılabilir.
Şu an bu yolla bağlanamazsınız. Her iki site de uzak (internetten erişilebilir, HTTPS) bir MCP sunucusu ister. Bu sitenin MCP sunucusu ise yerel çalışıyor — yani yalnızca kendi bilgisayarınızdaki Claude ile. Web arayüzlerinden bağlanmak için MCP sunucusunun sunucuya kurulup adres verilmesi gerekir; istendiğinde yapılabilir.

O zamana kadar ChatGPT için yukarıdaki “kendi GPT'niz” yöntemi aynı işi görür — MCP değil ama aynı işlemleri yapar.

Adım 3 — Ne diyebilirsiniz

Bağlantı kurulduktan sonra normal cümlelerle konuşun. Örnekler:

  • “Alphacam'de takım telafisi konusunda bir yazı yaz, taslak olarak kaydet.”
  • “Taslakta bekleyen yazıları listele.”
  • “Kaba paso yazısına bir bölüm daha ekle.”
  • “Nesting yazısını yayınla.”
  • “Hangi etiketlerde kaç yazı var?”
Önce taslak isteyin. Yapay zekâya doğrudan “yayınla” derseniz yazı okumadan siteye çıkar. Alışkanlık olarak taslak isteyip panelden okuyun, sonra yayınlayın.
